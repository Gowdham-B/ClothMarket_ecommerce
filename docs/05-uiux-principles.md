# UI/UX principles (Modules 1–4)

- Prioritise search and deal information over decoration.
- Keep product/platform/price/saving grouped to reduce memory load.
- Use clear labels and feedback for saves, comparison, filters, redirects, and unavailable products.
- Use progressive disclosure: list summary first, details and price history on inspection.
- Provide semantic controls, focus visibility, readable contrast, touch-sized controls, reduced-motion support, and responsive layouts.
- Research assumptions must be tested through interviews, task tests, and feedback collection; no research is fabricated.
