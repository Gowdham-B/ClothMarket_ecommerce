# API design

Current mock endpoints:

- `GET /api/v1/products?q=`
- `GET /api/v1/products/{id}`
- `GET /api/v1/search?q=`
- `GET /api/v1/platforms`

Future endpoints will add pagination, validation, user-owned wishlist resources, authenticated profile resources, price history, and admin controls under `/api/v1/admin`.
